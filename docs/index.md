# Peermate

Chess against the computer, with a friend on the same phone, or online with anyone, phone to phone. No account, no ads, no tracking, and no Peermate server.

- **Play the computer** at 10 levels, then review the game move by move.
- **Play online:** quick match by rating, or challenge friends you add by QR code. Games run directly between the two phones.
- **Free and open source:** the code is at [github.com/peercommons/peermate](https://github.com/peercommons/peermate).
